# 华理宿舍电量查询

一个给华东理工大学学生用的非官方 Android 工具：查寝室还剩多少电，也能看看最近的用电变化。

## 能做什么

- 支持奉贤、徐汇两个校区。
- 查询楼栋和寝室的当前剩余电量。
- 记住上次选过的校区、楼栋和寝室，下次打开可以接着用。
- 把自己的寝室设为“我的寝室”，只为它记录用电趋势。
- 查看最近的用电曲线；点开后可以左右滑动查看较长时间的历史。
- 充电后电量明显上升，会在曲线上标出来。
- 自己设置低电量阈值，低于阈值时接收提醒。
- 有新版本时接收更新提醒，并打开最新版 APK 下载地址。
- App 被系统清理后，服务器仍会继续每小时记录“我的寝室”电量。

## 怎么用

1. 选择校区和楼栋，输入寝室号，点击“查询”。
2. 想看趋势，就把查询结果设为“我的寝室”。
3. 想接收提醒，在“低电量提醒”里设置阈值并开启通知。

第一次开启提醒时，请允许 App 发送通知；版本更新提醒也使用同一通知权限。

## 说明

普通查询不会作为历史记录保存；只有设为“我的寝室”后，才会持续记录趋势。这个项目与华东理工大学没有隶属或授权关系，仅供个人使用。
