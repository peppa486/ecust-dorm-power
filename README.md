# 华理宿舍电量查询

一个面向华东理工大学学生的非官方 Android 宿舍电量查询工具。

> 本项目与华东理工大学无隶属或授权关系。

## 主要功能

- 支持奉贤、徐汇两个校区。
- 查询楼栋和寝室的实时剩余电量。
- 自动记住上次选择的校区、楼栋和寝室。
- 设置“我的寝室”，由服务器持续记录自己的用电趋势。
- 查看近 48 个采样点的趋势缩略图，以及最长 14 天的历史曲线。
- 详情曲线可左右拖动，横轴为时间，纵轴为剩余电量。
- 识别充值造成的电量明显上升，并在曲线上标记。
- 自定义低电量阈值，并在电量降低到阈值时提醒。

## 下载使用

下载并安装：[Android APK](mobile/releases/ecust-dorm-power-1.1.0-release.apk)

打开应用后：

1. 选择校区、楼栋，输入寝室号。
2. 点击“查询”。
3. 如需趋势和提醒，点击“设为我的寝室”。
4. 在低电量提醒中设置阈值并开启提醒。

## 后台提醒说明

设置“我的寝室”后，服务器会在整点附近持续采样并保存历史，不依赖 App 是否在后台。Android 本地提醒仍受系统后台权限影响；远程提醒还需要配置推送服务。
