# Android App 计划

## 目标

维护一个面向华东理工大学学生的 Android 宿舍电量查询工具，继续使用 `https://power.ecust.cc` 提供楼栋、电量、趋势和提醒服务。

## 已完成

- 奉贤、徐汇校区切换，以及楼栋和寝室查询。
- 每个校区分别记住上次选择，启动时自动恢复。
- “我的寝室”只对当前安装实例生效。
- 服务端登记关注寝室，并在整点附近采样；App 不运行时也会继续记录。
- 首页趋势缩略图、可横向拖动的历史曲线和充值跳变标记。
- 用户自定义低电量阈值。
- Android 本地提醒，以及可选的服务端远程推送通道。
- Android Studio 原生工程和可安装 Release APK。

## 当前边界

- 历史数据默认保留 14 天。
- 服务器采样按整点附近执行，不保证精确到每 60 分钟。
- 远程通知需要推送服务提供有效令牌和凭据；未配置时不影响服务端采样。
- 手机主动强行停止 App 后，本地后台任务不保证运行；服务端采样不受此影响。

## 后续优化

1. 完善 Android 真机通知链路和推送凭据配置。
2. 优化趋势图时间跨度、拖动体验和长时间历史浏览。
3. 继续统一前端视觉、加载态、异常态和无障碍交互。
4. 完成不同 Android 版本、弱网、升级安装和省电策略下的回归测试。

## 发布检查

- 使用 Android Studio 打开 `mobile/android/`。
- 使用 Release 构建生成 APK，并在真机安装验证。
- 发布前检查服务端健康状态、HTTPS、数据库备份和通知权限。
- 不在客户端保存服务端密钥。
