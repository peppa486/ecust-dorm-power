# 验收记录

## 已验证

- 服务端 35 个 Node 测试通过。
- 服务端 JavaScript 语法检查通过。
- Android App TypeScript 检查通过。
- `npm run smoke` 启动服务并通过 `/health`。
- 普通查询不写入历史；设置“我的寝室”后由服务端按整点附近采样。
- 同一寝室的多个设备合并采样，最后一个设备取消后清理历史。
- 历史数据默认保留 14 天，长期未更新的设备关注记录自动清理。
- 充值跳变会标记在趋势数据中，不计入普通耗电统计。
- 查询缓存有容量上限，同寝室并发查询合并为一次学校请求。
- `npm audit --omit=dev --audit-level=high` 无漏洞。
- Android 生产 APK 构建通过，真机安装验证通过后再发布 Release。

## 外部依赖

- 电量数据来自学校现有电费查询页面；学校维护、接口变化或网络异常可能导致查询暂时不可用。
- 远程低电量通知需要推送服务提供令牌和相应凭据；没有这些配置时，服务器仍会继续采样并保存趋势。
- 版本更新提醒使用独立的设备登记，不要求用户设置“我的寝室”；发布脚本会先更新版本清单，再向已登记设备广播通知。
